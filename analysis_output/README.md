# Analysis output plots

This folder is generated by running:

```bash
python process_fopra45.py
```

The plots are intended to be report-ready diagnostic figures for the FoPra 45 photoluminescence analysis.  The CSV and text files in this folder contain the numerical values used in or extracted from these plots.

## `01_calibration_spectrum.png`

Shows the measured He-Ne plasma calibration spectrum after conversion from the raw spectrometer axis to calibrated wavelength using the fitted linear calibration.  The vertical dashed lines mark the literature plasma lines used for the calibration.  This plot is mainly a sanity check: the strong measured plasma peaks should lie close to the dashed reference wavelengths.

## `02_calibration_curve.png`

Shows the calibration relation between raw spectrometer wavelength and known He-Ne plasma-line wavelength.  The points are the assigned measured/reference line pairs; the line is the fitted linear calibration used by the rest of the script.  A nearly straight relation is expected because only a small wavelength range is corrected.

## `03_calibration_residuals.png`

Shows the difference between fitted and literature calibration wavelengths for each He-Ne line.  The RMS of these residuals is written to `results.csv` and `summary.txt`.  Residuals of order one nanometer are plausible for this dataset because the peaks are broad and the setup/calibration were not optimized for high-precision spectroscopy.

## `04_cooldown_spectra.png`

Overlays the processed cooldown spectra.  Each spectrum is converted to counts per second, corrected by subtracting the averaged background with the same integration time, despiked to suppress isolated cosmic-ray events, wavelength-calibrated, normalized by its own maximum, and plotted with transparency.  The overlay is meant to show how the luminescence lines appear and shift while the sample is inserted into the helium dewar.  The curves are not vertically offset, so intensity should not be compared absolutely from this figure; it is primarily for identifying spectral shifts and line evolution.

## `04_warmup_spectra.png`

Overlays the processed warmup spectra using the same normalization and background-subtraction pipeline as the cooldown plot.  The script starts the warmup series at file number 7 because earlier spectra did not show visible heating effects.  This plot is a backup/qualitative temperature-series diagnostic; the cooldown series should usually be preferred for the report if it is cleaner.

## `05_cooldown_temperature_series.png`

Shows the temperature estimate extracted from the multi-quantum-well luminescence peak for the cooldown series only.  The cooldown x-axis is intentionally reversed: the tick labels are the original spectrum numbers in reversed order, so the plot follows the requested cooldown ordering.  The y-values are not recalculated or changed by this display choice.  The temperature should still be interpreted cautiously because the experiment infers temperature indirectly from luminescence.

## `05_warmup_temperature_series.png`

Shows the temperature estimate extracted from the multi-quantum-well luminescence peak for the warmup series only.  The warmup x-axis uses the original increasing spectrum-number order.  The warmup data start at file number 7 because earlier files did not show visible heating effects.

## `06_bottom_average_peaks.png`

Shows the bottom-of-dewar spectra averaged by measurement time.  The script averages the 10 s bottom spectra separately from the 30 s bottom spectra.  The 30 s average is used for weaker AlGaAs/GaAs-related features, while the 10 s average is used for the stronger quantum-well peaks to reduce saturation and scaling problems.  Vertical markers identify the AlGaAs peak, the GaAs substrate peak candidate, and the quantum-well lines used in the numerical analysis.

## `07_well_width_model.png`

Compares the measured QW transition energies with simple quantum-well models.  The finite-well curve is calculated from the lowest even finite-well solution for electron and heavy-hole confinement, corrected by the digitized heavy-hole exciton binding-energy curve from the manual.  The infinite-well curve is included as a comparison model and is expected to overestimate confinement energies for finite barriers.  Horizontal dashed lines show the measured QW transition energies; their intersections with the model curves give the estimated well widths listed in `results.csv` and `summary.txt`.

## Related numerical files

- `results.csv`: calibration constants, Al content estimate, band offsets, peak energies/FWHM values, well-width estimates, and spectral-resolution comparison.
- `temperature_series.csv`: per-spectrum MQW peak wavelength, energy, FWHM, effective zero-temperature reference energy, and inferred temperature.
- `summary.txt`: human-readable version of the most important entries from `results.csv`.
